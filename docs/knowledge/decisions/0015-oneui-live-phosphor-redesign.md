# 0015 — Android-редизайн: One UI 8.5 / «живой фосфор»

- **Статус:** принят (мокапы утверждены владельцем 2026-08-01)
- **Дата:** 2026-08-01
- **Зона:** `apps/android/` (только UI-слой: `ui/`, без сети и сервиса)

## Контекст

Приложение адаптировалось под раскрытый Fold 8, но выглядело чужеродно на One UI:
жёсткие прямоугольники (радиус 6 dp), hairline-рамки, статичные карточки, дубль бренда
на раскрытом экране, рвущийся заголовок «Передач / а.», пустые зоны. Плюс появились
новые форм-факторы 2026 (Z Fold 8 Ultra c внутренним 8″ 3:2 и внешним 21:9,
Z Flip 8 с основным 6.9″ 21:9) и Flex Mode.

## Решение

Характер оставить (тёплый чёрный + фосфорный лайм + моно-капс), форму привести
к One UI 8.5 / Material 3 Expressive, телеметрию сделать живой.

### Design tokens

| Токен | Значение |
|---|---|
| Радиус карточки | 26 dp |
| Радиус вложенной карточки | 18 dp |
| Чипы, кнопки, nav-элементы | pill (999) |
| Главная кнопка | pill, высота 56 dp |
| Gutter | 20 dp единый (было 18/22 вразнобой) |
| Поверхность карточки | tonal: `bgElev` + top-light градиент `bone` 2.8 % → 0 |
| Рамка карточки | `bone` 5.5 % (вместо `hair` 1 dp) |
| Elevation | glow (лаймовые тени), НЕ чёрные тени |
| Spring-кривая входа | overshoot, аналог `cubic-bezier(.34,1.56,.64,1)` |

### Паттерны

- **Остров** (группа KV-строк с inset-разделителями, как в настройках One UI) —
  вместо стопки отдельных карточек. DNS-индикатор — первая строка острова.
- **Scope + Mux — одна карточка** с горизонтальным разделителем.
- **Кнопка**: tonal (подключено) / filled lime (ожидание) / warn (connecting) /
  disabled 45 % (disconnecting). Shape-morph при нажатии (pill → 26 dp).
- **Живая телеметрия**: дышащая аура за контентом (7 s, цвет = состояние),
  пульс полос мультиплекса с фазовым сдвигом, ping-кольцо на DNS-точке,
  glow заголовка состояния, стаггер-вход карточек со spring.
- Полосы мультиплекса: ширина клампится 8–22 dp (не расползаются на широких).
- Бренд на раскрытом экране живёт только в drawer; в drawer добавлена карточка
  активного профиля (закрывает пустоту).

### Раскладки по форм-факторам

| Форм-фактор | dp | Раскладка |
|---|---|---|
| Телефон (S21) | 360×800 | компакт, капсула снизу |
| Fold 8 сложен | 475×751 | компакт, больше воздуха |
| Вытянутые (Flip 8 основной, Fold 8 Ultra внешний) | ~385×900 | компакт + итоги сессии |
| Fold 8 раскрыт «книжка» | 933×704 | drawer + hero на всю ширину + 2 колонки |
| Fold 8 раскрыт портрет | 704×933 | rail + 1 колонка, кламп 560 dp |
| Flex Mode (Fold/Flip полусложен) | делится шарниром | верх — «экран» (hero+scope), низ — «пульт» (mux+DNS+кнопка) |

Flex Mode определяется через `WindowInfoTracker` → `FoldingFeature`
(`state == HALF_OPENED && orientation == HORIZONTAL`), не через размеры окна.
Существующие пороги `sw600/w840` (`AdaptiveInfo.kt`) не меняются — ландшафт
обычных телефонов и Tab S11 не трогаем.

### Журнал: читаемость важнее полноты (v0.28)

- Фильтр по умолчанию — **INFO** (мин-порог: INFO/WARN/ERROR). DEBUG-рукопожатия
  (`tls.client_hello`, `mtls.cert_verify` на каждый из N стримов) забивали экран.
- **Свёртка повторов**: подряд идущие строки с одинаковыми (level, category,
  message) сворачиваются в одну со счётчиком `×N`. Системные колбэки сети
  прилетают десятками подряд.
- **Подсветка значений**: всё после `=` рисуется цветом `bone`, служебная часть —
  `textDim`. Глаз ищет данные, а не служебные слова.
- Категория — inline-текст цвета `bone` + ` · `, НЕ плашка: плашка на каждой
  строке была визуальным шумом. Строки разделены inset-волоском `bone 3.5 %`.

### Термины объясняются по тапу (v0.28)

Чипы карточки «Транспорт» и строки KV-острова кликабельны и открывают диалог
«что это такое» с объяснением на человеческом языке (mTLS, SNI passthrough,
мультиплекс, DNS через туннель, маршрут, выданный адрес, личность, подписка).
Строки живут в `values*/strings.xml` под префиксом `explain_*`. Причина: термины
протокола ничего не говорят человеку, который хочет знать лишь, защищён ли он.

### Честный статус эндпоинта (v0.28)

`ProfileCard` больше не пишет «offline» по результату TCP-ping: пинг на `:443`
режется DPI, хотя туннель жив. Для активного профиля источник истины —
`VpnStateManager.derivedVpnState` («в работе»), для остальных — «нет отклика».

### Философия навигации (подтверждено владельцем)

Админ-вкладки в навигации НЕТ ни на одном форм-факторе. Каждое подключение
самодостаточно: админ-панель доступна только с карточки админ-профиля в
Настройках (`cachedIsAdmin == true`). Навигация всегда: Поток · Журнал · Настройки.

## Утверждённые мокапы

Итеративно утверждены три борда (HTML со встроенными шрифтами проекта, 1 px = 1 dp):
v2 «живой фосфор» (3 состояния Fold 8), v3 «полный борд» (все экраны, все состояния
кнопок, диалоги, QR, админ, Flex), v4 «борд по устройствам» (6 форм-факторов).
Источники: scratchpad сессии 2026-08-01; ключевые скриншоты — в PR/коммитах редизайна.

## Отвергнутые альтернативы

- **Полный переход на WindowSizeClass** — ломает ландшафт телефонов (см. комментарий
  в `AdaptiveInfo.kt`); оставлены ручные пороги.
- **Тени Material вместо glow** — на тёплом чёрном фоне не читаются.
- **Отдельная вкладка Админ** — противоречит философии «каждое подключение
  самодостаточно».
